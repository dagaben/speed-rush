# Speed Rush

Dusk canyon highway. Drift, jump, nitro. Five timed laps.

**Play here:** https://dagaben.github.io/speed-rush/

- WASD / arrows to drive
- Space to brake and drift
- B / Nitro for a 5-second boost
- On phones: steer pad + Gas / Brake / Nitro

After 5 laps, post a 3-letter tag. On this GitHub Pages build, times save in your browser. The Grok-hosted app keeps the shared world board.
